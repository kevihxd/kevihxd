### 🚀 Perfil Profesional

Ingeniero de software en formacion, Desarrollador de Software semi-Senior y Docente Técnico con sólida experiencia en el diseño de arquitecturas empresariales escalables, gestión de infraestructura IT e integración de hardware. 

Especializado en el ecosistema **Java (Spring Boot)** para soluciones backend robustas bajo principios de **Clean Code** y arquitecturas modulares en capas. Combino el desarrollo de software de alto nivel con el diseño electrónico, diagnóstico de hardware a nivel de componente y sistemas embebidos.

- 🏛️ **Arquitectura & Backend:** Diseño de APIs RESTful de alto rendimiento utilizando **Java 21, Spring Boot 3, Spring Data JPA** y **PostgreSQL**, aplicando patrones modernos como *Java Record DTOs*.
- 🌐 **Ecosistemas & Automatización:** Desarrollo de plataformas de gestión de calidad (SGC), sistemas LMS, flujos de trabajo documentales y automatización avanzada con **Google Apps Script**.
- 🔬 **Hardware & Docencia:** Instructor técnico en reparación electrónica, micro-soldadura, diseño de circuitos y programación de microcontroladores (**Arduino, C/C++**).
- 🤖 **Enfoque actual:** Desarrollo de asistentes de análisis de mercados financieros en tiempo real orquestados con Inteligencia Artificial.
